# Lab08_TH

Dự án React được khởi tạo bằng **Create React App** và cấu hình định tuyến bằng **react-router-dom**.

## Cấu trúc chính

- `src/components`: `Header`, `Footer`, `MovieCard`
- `src/pages`: `HomePage`, `DetailPage`, `AboutPage`
- `src/App.js`: cấu hình route cho `/`, `/detail`, `/about`

## Git Flow cơ bản

Đã thiết lập hai nhánh làm việc cơ bản:

- `main`: nhánh ổn định
- `develop`: nhánh tích hợp tính năng

Để đẩy cấu trúc ban đầu lên GitHub cho cả hai nhánh:

```bash
git push -u origin main
git push -u origin develop
```

## Chạy dự án

```bash
npm install
npm start
```
